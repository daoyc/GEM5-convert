# 第 4 轮：预测组件注册与 FTQ / FSQ

两份输入的默认配置都选择 FTB。读取构造函数的 `components.push_back`，并与同一预测器类内的 Python 参数对应，得到 uFTB、uRAS、FTB、TAGE、RAS、ITTAGE 六个注册项。选择 BTB 后改为八个，其中包含 GShare 和 MGSC。BTB 的 uRAS 注册位于注释内，跳过该注册；Python 中单独存在的声明不算注册。

**改动**：BPU 子图按已注册项生成节点，FTQ 子图增加 FSQ 入队、按 streamId 查找、目标项入 FTQ、供给及消费后释放路径。记录预测器选择条件、声明容量以及 ideal 配置赋值。

**验证**：调用正常转换入口重新读取 GEM5-1 和 zenas-dev，各生成一份 JSON，分别得到 1,225 个声明和 2,422 / 2,423 条源码关系。逐项核对声明与注册行；两份输出默认 FTQ/FSQ 为 128/64，显式 BTB 且开启 ideal 为 64/64。两份默认产物都生成 `ftq.from-stream`。动态预测器名称的检查结果为“未知”。
